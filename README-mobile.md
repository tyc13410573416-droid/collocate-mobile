# 词伙手机版：Supabase 云同步版

## 创建 Supabase 云端数据库

1. 打开 Supabase，创建免费项目。
2. 进入 SQL Editor，把 `supabase-schema.sql` 全部粘贴执行。
3. 进入 Project Settings > API，复制：
   - Project URL
   - anon / public key
4. 发布这个文件夹到 HTTPS 网站。
5. 手机和电脑打开同一个网址，在右上角“云端同步”中填写相同的：
   - Supabase 项目地址
   - anon key
   - 同步 ID（自己设置一串随机文字，例如 `tyc-collocate-7f3a`）
6. 有数据的设备点“上传到云端”，另一台点“从云端读取”。之后可以勾选自动上传。

## 安全和备份

网页中只能填写 anon key，不能填写 service_role key。同步 ID 相当于这份数据的私密口令，不要发给别人。页面仍保留“导入与备份”，建议定期下载完整备份。

当前同步以整份 state 为单位，并带版本冲突保护。如果两台设备都改过数据，先从云端读取，再上传，避免覆盖较新的记录。

## 手机界面

页面使用窄屏优先布局：顶部固定状态栏、横向导航、卡片式学习入口、整宽输入框和大触控按钮；可以直接添加到手机主屏幕。

## 三阶段循环学习

每个学习组使用独立的 FIFO 学习队列。词伙进入队列时为 Stage 1，答对后按 Stage 1 → Stage 2 → Stage 3 逐级升级；答错任何阶段都会重置为 Stage 1，并排到队尾。Stage 3 答对后进入待听写池，池中累计 10 条时暂停主队列，进入整体听写。

整体听写答对的词伙毕业并从本组移除；听写答错的词伙重置为 Stage 1，再排到主队列队尾。学习页顶部会显示当前阶段、主队列数量和听写池数量。

## 词伙内容

每条词伙包含英文表达、中文提示、英文例句和例句中文释义。导入 CSV 时支持以下列：

```text
topic,zh,en,alternatives,example,exampleZh,source
```

旧数据没有 `exampleZh` 时，页面会使用词伙中文提示作为备用释义；新增或编辑词伙时可以单独填写例句中文释义。
