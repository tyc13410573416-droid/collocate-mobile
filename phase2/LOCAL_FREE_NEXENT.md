# 本机免费 Nexent 与照片识别

此电脑已安装 Nexent v2.8.1，使用 WSL2 Ubuntu 24.04 与 Docker Engine，不依赖 Docker Desktop。安装数据位于 `E:\MedTraceNexent`，不覆盖原 GitHub Pages 演示站。

## 使用

1. 打开安装目录中的 `启动MedTrace.cmd`，等待服务检查通过。
2. 浏览器打开 <http://127.0.0.1:5052>。上传自己的 JPG、PNG 或 WebP，补充已知性别，再点击“生成带来源解读”。
3. 展开识别原文，对照原图核对数值与单位。点击“图1/图2”等样本按钮仍然是预置数据演示；选择本机文件才会运行真实识别。
4. Nexent 平台位于 <http://127.0.0.1:3000>。日常使用工作台无需登录平台，管理账号保存在本机私有安装目录，未发布到仓库。

`停止MedTrace.cmd` 只终止本项目的 `MedTraceNexent` WSL 发行版，数据保留；下次用启动入口恢复。没有添加 Windows 开机任务。休眠、关机或停止后，本地识别不可用。

## 已安装的免费路径

真实上传 → Nexent MinIO → Nexent Agent → `analyze_medical_image` MCP → RapidOCR-ONNX CPU 读图 → 表格结果列对齐 → `parse_report` → `query_reference` / `evidence_gate` → 网页显示。

- 路由模型：Qwen3-1.7B，官方 GGUF 经本机量化为 Q4_K_M，由 llama.cpp CPU 服务运行。
- OCR：RapidOCR-ONNX 1.4.4，CPU 运行；不需要云视觉模型账号或付费 API。
- 医学依据：现有 34 条参考库和规则。此路径是参考条目查询，没有执行向量召回或重排序，页面不会伪装显示这类指标。
- 结果：保存在私有短期结果目录，使用随机回执与本次上传地址绑定。网页仅在观察到本次图片工具调用后读取真实结果，不让小模型重写检验值。回执 15 分钟后失效，下次保存结果时清理过期文件。
- 授权：上传与 Agent API 使用本机服务端登录，每次请求取有效会话，账号密码与令牌不发送给浏览器、不写入网页或仓库。

目前没有接入付费模型、充值、云主机或收费 OCR。电费、网络和本机存储仍由用户承担。

## 实测与限制

已通过本机 HTTP 接口和浏览器上传图2真实像素，读取葡萄糖 **16.1 mmol/L**、CRP **16.0 mg/L**、肌酐 **63 μmol/L**，另外匹配 TBIL、TP、ALT。一次 HTTP 实测约 36 秒，冷启动和 CPU 占用可能使请求更慢。模型不是医学大模型，只负责调用工具。

当前仅可靠处理能对齐结果列、单位且知识库已收录的部分表格项目。模糊、歪斜、复杂长图或未确认字段会返回复核，不能承诺所有照片均能识别。OCR 评分未校准，不等于正确率。医学参考适用条件与来源版本仍需团队核对。

`pass` 仅表示证据允许显示，不表示指标正常。`review` 保留原始读数并停止确定性异常方向。用药核查沿用现有有限演示规则，未命中不代表用药安全；不输出停药、换药、调剂量或诊断建议。

PDF 可预览；本地 OCR 通道要求先导出成图片。上传照片不会回放内置样本结果。

队友统一使用固定入口：<https://tyc13410573416-droid.github.io/collocate-mobile/>。运行 `开启队友共享.cmd` 后，页面会自动查找当前 OCR 地址，无需队友填写后端或反复换链接。连接记录存放在仓库独立的 `codex/ocr-runtime` 分支，只包含公开服务地址与状态，不包含令牌、账号或报告。

共享监控由 Windows 独立托管，不依赖启动终端的存活；本机注册了当前用户的 `MedTrace-Team-OCR` 登录任务，登录后自动启动，进程异常退出时由 Windows 尝试重启。安装器也提供当前用户启动文件夹作为无管理员权限的回退。没有存储 Windows 登录密码，也不使用系统管理员权限运行共享。

监控会检查连接、恢复中断的共享进程并更新地址；网络故障仍需等待网络恢复。共享期间使用进程级 Windows 电源请求防止自动空闲休眠，不改电源计划，关闭共享后释放。关机、手动休眠或合盖休眠仍会停止真实 OCR。重启后需登录 Windows，冷启动可能需要几分钟；也可运行共享入口手动恢复。

本机 API 使用 Gunicorn 单进程、4 线程运行，systemd 在进程异常退出时重启；图片任务保留单并发限制，健康检查和其他页面请求可同时处理。

临时 HTTPS 后台连接仍由免费隧道提供，不保证全天在线，也没有可用性 SLA。固定网页、预置案例不依赖这台电脑；当 OCR 离线时会明确显示离线，不能回放假结果充当本次图片识别。后台地址变化后页面自动读取新地址；已有页面可重新提交以检查连接。

`关闭队友共享.cmd` 会停止监控、关闭隧道并标记 OCR 离线，本机工作台仍可使用。停止整个 MedTrace 时也会关闭共享。共享只连接本机 5052 工作台，不公开 Nexent 管理后台。多位队友同时提交时，只处理一份图片，其余请求提示稍后重试。

## 图片人工核对

识别结果出现复核时，可使用“手动核对数值”和“补充缺失信息”。逐项勾选确认后，由后端重新运行单位标准化和证据门控，未选项目仍需核对。每项指标旁可悬浮或点击查看对应知识库参考条目。当前未提供标准全文页码，摘要不会标成标准原文。

原始 OCR、不确定字段及人工修改记录均保留；核对会话约 15 分钟后过期。详细说明见 `phase2/人工核对与来源关联说明.md`。
