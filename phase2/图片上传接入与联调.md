## 前后端接口

`POST /api/analyze-image`：multipart `file`、`gender`、`raw_text`（可选）、`medications`。单个文件不超过 10 MB。不接受浏览器传上游地址或模型 Token，不记录图片、患者内容和原始文件名。

配置/参数错误使用 JSON + HTTP 4xx/503。开始传输后返回 `application/x-ndjson`：

```json
{"type":"stage","stage":"uploading"}
{"type":"stage","stage":"uploaded"}
{"type":"stage","stage":"agent_submitted"}
{"type":"stage","stage":"vision_reading"}
{"type":"stage","stage":"checking_evidence"}
```

后两个阶段仅在观察到真实工具事件时出现，随后返回 `result` 或 `error`。流式错误可能仍为 HTTP 200，必须读取最终事件。

结果保留冻结字段与挂载点，另附 `image_transcription={raw_text,readable,uncertain_fields}`。网页以纯文本展示转录供原图核对，未确认读数不能 pass。访问日志不记录报告内容；文件上传后的保留周期由 Nexent/MinIO 管理员配置。
